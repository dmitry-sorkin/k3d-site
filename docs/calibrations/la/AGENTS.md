# AGENTS — docs/calibrations/la/

PA (Pressure Advance / Linear Advance) calibrator: a Go program compiled to WebAssembly,
embedded in the K3D site as an MkDocs Material page. Generates G-code for tower-style PA
calibration, including adaptive PA against flow rate / acceleration / smooth time.

## Build

Two independent chains. **Touching `main.go` requires both**:

```bash
# 1. Rebuild WASM (after main.go change). Requires Go >= 1.26 (see go.mod).
./build.sh                 # Linux / macOS / WSL
build.bat                  # Windows

# 2. Rebuild the static site (after any docs/ or asset change)
python -m venv .venv && .venv/Scripts/activate
pip install -r .github/workflows/requirements.txt
properdocs build --clean
```

`build.sh`/`build.bat` run `GOOS=js GOARCH=wasm go build -o assets/wasm/k3d_la_lib.wasm main.go`.
The resulting ~3.3 MB `assets/wasm/k3d_la_lib.wasm` **must be committed** — the site is static.

## Data flow

`calibrator.md` (HTML form, IDs `k3d_la_*`) ⇄ `lib.js` (localStorage, validation, lang strings)
⇄ `main.go` via `syscall/js` ⇄ `streamsavermin.js` (browser downloads `.gcode`).

The Go side never renders DOM itself — every value is fetched via
`js.Global().Get("document").Call("getElementById", "k3d_la_xxx")`. Language strings
cross the same boundary through `getLangString(key)` → `window.lang.getString(key)`.

## Invariants

1. **Version constants stay in sync.** `calibratorVersion` in `main.go` and `calibrator_version`
   in `lib.js` (both near the top). Mismatch surfaces at runtime as "Please hard refresh".
   Bump together only when the G-code format itself changes.
2. **Form element IDs are the public API across the three layers.** `k3d_la_xxx` appears in
   `calibrator.md` markup, `main.go` `getElementValue` calls, and `formFields` array in
   `lib.js`. Renaming requires all three updates.
3. **Validation ranges in `main.go` match the user-facing description in `calibrator.md`**
   and the `[min-max]` quoted in both language dictionaries in `initLang` (`lib.js`).
4. **`assets/wasm/k3d_la_lib.wasm` is rebuilt and committed on every `main.go` change.**
5. **Generated G-code is append-only** with a `;generated by K3D PA Calibrator … ;---------`
   header. External tools may rely on this.

## Conventions

- Russian comments in Go, Russian UI strings, Russian prose in `index.md` / `calibrator.md`.
  English only for identifiers, paths, tool names.
- Form rows in `calibrator.md` are grouped **printer → filament → calibration**.
  Keep this order when adding parameters.
- Adding a parameter = add to `formFields` in `lib.js`, add a row in the right group in
  `calibrator.md`, add entries to both `en` and `ru` cases in `initLang`, declare the
  global in `main.go`, validate the range.
- Tunable defaults live as top-of-file consts in `main.go`: `retractSpeed`, `retractLength`,
  `log`, `maxSeparatorOffset`, `relativeExtrusion`.

## Don't

- Don't edit `wasm_exec.js` or `streamsavermin.js` — vendored.
- Don't bump the two version constants separately.
- Don't add a new language without also teaching Go's `getLangString` callers the new keys.
- Don't ship a `main.go` change without rebuilding WASM.
- Don't add Go packages beyond `syscall/js` without a clear need.
